# Plot Themes

Plot Themes

## Usage

``` r
theme_heat(
  base_size = 11,
  base_family = "",
  base_line_size = base_size/22,
  base_rect_size = base_size/22
)
```

## Arguments

- base_size:

  base font size

- base_family:

  base font family

- base_line_size:

  base size for line elements

- base_rect_size:

  base size for rect elements

## Value

Adding a heat theme to all plots generated by using the ggDoubleHeat
package.
